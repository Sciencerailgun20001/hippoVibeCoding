一句话变出一个世界

90 分钟 核心认知：我跟 AI 说话，AI 就能做游戏
▾

环节

破冰 10min — 老师打开一个超级玛丽风格的游戏链接，全班用手机扫码玩 3 分钟。问："你们猜猜，这个游戏写了多少行代码？——零行。做它的人只干了一件事：说话。"
老师演示 15min — 投屏 Trae 界面，逐字念出 prompt，回车，等 10 秒。游戏窗口出现。全班"哇"。
帮我做一个网页游戏，要求： - 一个像素风格的小人，站在绿色的草地上，背景是蓝天和白云 - 可以用键盘的上下左右方向键控制小人走路和跳跃 - 小人有走路动画和跳跃动画 - 游戏窗口大小适合手机屏幕 - 把代码写在一个 index.html 文件里
每个孩子自己来 45min — 每个人对自己面前的 AI 说出上面那句话。跑起来的人去帮旁边还没跑起来的。没跑起来的：把红字复制发给 AI，说"这个报错了，帮我修好"。
第一次迭代 15min — 每人自选一句改一个东西：背景颜色、小人样子、地面、加云朵。一次只改一个，跑通了再改下一个。
收尾 5min — 宣布：下节课加坏人、金币和生命。

产出验收清单

  • 学生打开了 Trae 并连上了 DeepSeek
  • 每个人都生成了一个能打开的 HTML 文件
  • 小人大致能用方向键走路和跳跃
  • 至少改了一个个性化的东西
2

我的游戏有敌人了

90 分钟 学会"一次加一个功能"的对话节奏
▾

老师带节奏，全班同步操作

第 1 步：加蘑菇敌人 — "帮我在游戏里加上 3 个蘑菇敌人：它们在平台上左右来回走动，红色身体有白色圆点，走到平台边缘自动掉头"
第 2 步：加金币和分数 — "金币散落在各个平台上，小人碰到金币消失、加 10 分。分数显示在屏幕左上角，大一点的字，白色"
第 3 步：加生命系统 — "小人一共 3 条命。跳到敌人头顶踩中，敌人消失。从侧面碰到敌人，扣一条命，小人闪几下。剩余生命用红色爱心显示在右上角"
第 4 步：加 Game Over — "生命用完的时候屏幕变黑，中间显示 Game Over，下面有'再来一次'按钮，点了重新开始"
自由加料 15min — "让敌人中有一个会飞的" / "加一个弹簧板" / "加一个加速道具" / "吃到金币有叮的一声"

产出验收清单

  • 有 3 个左右移动的蘑菇敌人
  • 有金币，能碰、能加分
  • 有生命系统，碰到敌人侧面会扣命
  • 命用完有 Game Over 画面
  • 至少加了一个自己想的料
3

设计我的第一关

90 分钟 从"东西散落"到"有起点、有推进、有通关"
▾
纸上画关 15min — 发 A4 纸 + 彩笔。画：起点、终点旗子、平台位置、坑、金币和敌人位置。不要画太复杂。
AI 搭关卡 30min — 学生拿着自己画的图，对 AI 描述关卡："帮我重新设计关卡：从左到右很长，地面中间有两段断开（坑），左边起点，右边红色旗子。中间有 3 层不同高度的平台……"
卷轴效果 — "小人走到屏幕中间以后，画面会跟着小人往右移，关卡大约 3-5 个屏幕宽"
通关画面 — "小人碰到红旗时画面显示 'You Win! 🎉'，背景彩带飘落，显示用时和最终得分"
分享按钮 — "在 You Win 画面加一个'分享给朋友'按钮，大一点、圆角、亮黄色。先占位，下节课配置"

产出验收清单

  • 有手绘关卡草图
  • 关卡有起点和终点旗子
  • 画面能跟着小人卷轴移动
  • 通关有 You Win 画面
  • You Win 画面上有"分享给朋友"按钮
4

这是我的风格

90 分钟 用 AI 生图制作全套个人美术素材
▾
批量生图 35min — 使用即梦/通义万相网页版，每个孩子生成 6 张素材：主角站立、主角跳跃、敌人、地面纹理、背景、标题画面背景。全部下载到桌面并命名好。
喂给 AI 替换 25min — 把图片拖到 Trae 项目文件夹，对 AI 说："帮我把游戏里的图片全部替换成我自己画的：主角站.png / 主角跳.png / 敌人.png / 地面.png / 背景.png"
开始画面 20min — "帮我做一个开始画面：背景用标题背景.png，中间显示游戏名字《XX大冒险》，下面两个按钮：'开始游戏'和'分享给朋友'。底部写'Made with Vibe Coding'"
互相试玩 10min — 全班站起来，走到别人电脑前玩别人的游戏。每人至少玩 3 个。

产出验收清单

  • 有了 AI 生成的 6 套美术素材
  • 主角和敌人换成了自己的图片
  • 地面和背景换成了自己的图片
  • 有游戏标题开始画面
  • 开始画面底部有"Made with Vibe Coding"
5

扫码就能玩 + 我的广告牌

90 分钟 把 HTML 变成永久链接 + 分享海报
▾
老师演示部署 15min — 打开 COS 控制台 → 上传文件 → 开启静态网站托管 → 拿到 URL → 手机扫码测试。老师提前写好批量上传脚本。
学生拿链接 25min — 老师批量上传全班文件到 COS，公布每个人的链接。链接格式：https://vibecoding-xxx.cos.ap-guangzhou.myqcloud.com/class01/student01/index.html
生成二维码 15min — 在 Trae 中对 AI 说："帮我在开始画面和 You Win 画面都加上二维码，用 qrcode.js CDN。二维码下面写'扫码来玩我的游戏！'"
制作分享海报 25min — 新建 share.html："背景渐变色，最上面写游戏名字，中间放手机线框图，下面写'我用 Vibe Coding 做的第一个游戏'，再下面放二维码，最下面写'扫码免费玩'"
传播实验 15min — 建群，每个学生发链接 + 海报。现场互扫。布置家庭任务：让至少 5 个人扫码玩。

产出验收清单

  • 每个人的游戏部署到了 COS，有永久链接
  • 链接在手机上扫码能打开
  • 游戏中有二维码
  • 有一张分享海报
  • 学生在群里发了链接和海报
6

发布会 + 我的游戏上架了

90 分钟 仪式感收尾 — 数据揭晓、上台展示、颁发证书
▾
数据揭晓 10min — 老师展示每个人的访问数据。访问量最高 3 人获得"传播之星"贴纸/小奖品。
每人 4 分钟发布会 50min — 投屏开始画面 → 说游戏名字和灵感 → 演示最得意的设计 → 投屏二维码："大家可以扫码玩！" 老师控制时间：3 分钟举牌提示，4 分钟推进。
家长连线/到场 15min — 提前通知家长进入腾讯会议。孩子展示时说："妈妈/爸爸，扫码玩一下我的游戏！"
结营 15min — 颁发证书 → 全班合影（手持游戏二维码的手机）→ 发放传播包（链接卡片 + 打印海报 + 15 秒录屏 + 证书）

产出验收清单

  • 展示了每个人的访问数据
  • 每个学生都上台做了发布会
  • 家长看到了孩子的作品
  • 每个学生拿到了证书 + 传播包
  • 全班合影（手持游戏二维码）

学生不学什么

这些都不教——学生只做三件事：说清楚想要什么、描述怎么改、分享出去

不学 HTML / CSS / JavaScript
不学变量、循环、函数
不学命令行、Git
不调试代码（报错粘回 AI）
不安装开发环境

学生只学三件事：

1. 说清楚自己想要什么
2. 看到不满意的地方，描述怎么改
3. 把做好的东西分享出去
